Card settings

First configure the card like Raspberry Pi Imager (Wi-Fi, user, SSH). MeteorCloud enrollment is optional. Written to the card’s boot partition; secrets are not sent to the server. Tick “Remember” only for non-secret fields.

Hostname, Wi-Fi and SSH login — the same ideas as OS customisation in Raspberry Pi Imager.

Not required for Wi-Fi or SSH. Turn this on to put enrollment settings on the card so the device can request a token on first boot. Upload a settings file above, or fill the boxes below.

Create one in MeteorCloud under Devices → Enrollment keys, or download a settings file from the console and copy the key. Give it an expiry date and revoke it when the batch is done.

On first boot the device asks to join with this key (request-token) and waits until an administrator approves it in the console.

    Back up a card

    Copies a card into an image file you can upload to MeteorCloud as an OS image. Nothing is written to the card. To turn a set-up device into an image every new device can use, run sudo meteorcli-prepare-image.sh on it first.

    The image then fits smaller cards; a prepared image grows back to the card on first boot.
