Card settings

Written to the card’s boot partition. Nothing here is sent to the server or saved by Meteor Imager, except the non-secret fields if you tick “Remember”.

The image’s first user is renamed to this name (or created). Only a hash of the password goes on the card.

The Wi-Fi password is stored on the card’s boot partition until first boot. Anyone with the card can read it.

Added for the user above, or the image’s first user.

Create one in MeteorCloud under Devices → Enrollment keys. Give it an expiry date and revoke it when the batch is done.

On first boot the device asks to join with this key (request-token) and waits until an administrator approves it in the console.

    Back up a card

    Copies a card into an image file you can upload to MeteorCloud as an OS image. Nothing is written to the card. To turn a set-up device into an image every new device can use, run sudo meteorcli-prepare-image.sh on it first.

    The image then fits smaller cards; a prepared image grows back to the card on first boot.
