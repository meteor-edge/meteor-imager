Card settings

Written to the card’s boot partition. Nothing here is sent to the server or saved by Meteor Imager, except the non-secret fields if you tick “Remember”.

Create one in MeteorCloud under Devices → Enrollment keys. Give it an expiry date and revoke it when the batch is done.

The Wi-Fi password is stored on the card’s boot partition. Anyone with the card can read it.
